# Fixture corpus for check (f)'s R3-OVERSTATEMENT leg — the wrapped-phrase cases.
# Read by `scripts/validate-tracking.sh --probe`, which materialises every case below as its own
# .md file in a temporary tree and runs the REAL sweep function (f_over_hits) over it.
#
# WHY THIS FILE EXISTS, AND WHY IT IS NOT IN ../r3-allowlist/ (2026-08-17, ledger F15 recurrence 5).
# The sibling corpus there is one datum PER LINE (`>>> ` prefixed). That format cannot express the
# defect this corpus measures: a phrase with a line break inside it. The guard it fed was probed
# with variants that were all written on one line, so the probe passed while the guard could not
# see its own ruled defect sitting in a shipped skill file — the phrase straddled the break between
# `refresh-templates.md`:464 and :465 and check (f)'s line-based grep returned 0 on that file.
# A probe built from variants that all share the defect's accidental formatting tests the pattern
# against itself. So the unit here is a CASE, not a line, and a case may be as many lines as it
# needs to be.
#
# FORMAT
#   `=== CASE <name> [flags]`   opens a case; every following line is verbatim content of <name>.md
#   `=== NOTE <text>`           ignored (provenance, rationale)
#   any other `=== ` line       a format error, reported by the probe rather than skipped
#   lines before the first case free-form header; `# COUNT: <n>` is asserted against the parse
#
# FLAGS — no flag means "must be reported as a violation"
#   CLEAN          must NOT be reported; a line the library wants to be able to write
#   WRAPPED        the overstatement phrase straddles a line break in this case, and the probe
#                  asserts the sweep says so. A future reflow of this file that quietly joins the
#                  lines would otherwise leave the corpus looking full while measuring nothing.
#   SUBJECT-BOUND  a CLEAN case that is clean BECAUSE of the FAQ/schema/markup conjunct, not
#                  because it lacks the phrase. The probe re-runs it with that conjunct made
#                  trivially true and requires it to fire. A legitimate case that stays quiet
#                  under that substitution is passing for a reason nobody tested.
#
# DO NOT REFLOW THIS FILE. The line breaks inside the cases are the measurement.
#
