# Weekly rank-check sheet — calorix.gr (manual, user-provided)

**Client:** Calorix — calorix.gr (Greek e-shop: heating, water heaters, heat pumps — Athens)
**Method:** every Monday ~09:00 the marketing coordinator runs each keyword on the same phone — mobile, incognito Chrome, location set to Athens, Greece, Greek interface — and records the best calorix.gr position found in the top 50 results (5 pages). NF = not found in the top 50. Same time, same device, same location every week.
**Tools connected:** none. No Search Console export at hand, no search-volume data, no click/traffic data, no keyword-difficulty data on file for any keyword below. SERP features are NOT recorded in this sheet. This file is the complete data set.
